Revision Website

This website has all the questions from the course, organised to make it easier to revise and track your progress. The questions come from ReHit quizzes, graded quizzes, worksheets and code writing activities from class.

How to use it

  • Pick a module. Each module has four sections: Theory, Code Tracing, Debugging and Code Writing.
  • Start with Important only. Switch to All questions when you want more practice.
  • Your progress is saved in this browser only.

The final exam will not have exactly the same questions, but practising these will prepare you for it.

Some explanations are AI-generated and may contain mistakes. If something doesn't make sense, ask your instructor.

Study tools

Practise the questions you answered incorrectly, see how much you have done, bookmark questions with your own notes, find any question, and back up your progress. Everything here is saved in this browser only.

Practise my mistakes

This lists the questions you answered incorrectly. A practice attempt is saved separately from your original result, so nothing in your progress record is reset. Questions appear in the bank's own order.

Bookmarked questions and your notes

Bookmark a question from the question card, then keep your own note with it. Notes are shown here as plain text and are saved in this browser only.

Search questions

Search looks at question IDs, titles, prompts, module numbers and topic names. It does not search answers, sample solutions or explanations.

Export your progress

This downloads one JSON file containing your answers, practice attempts, bookmarks and notes. It is the only copy of that file, so keep it somewhere safe: this website cannot get a deleted backup back for you.

Import a backup

Importing merges the file into what is already saved here. If the file and this browser disagree about the same question, your local answer is kept unless you tick the box below. Nothing is deleted, and you can download a copy of your current data before applying the import.
